## Installation

**Windows:** extract the entire portable ZIP and open ZLHRS Theme Studio.exe. Keep all files together.

**Mac:** extract the ZIP for your processor and move the app to Applications. If macOS blocks the unsigned app, use System Settings → Privacy & Security → Open Anyway after attempting to open it. Only allow a download you trust from this repository.

**Linux:** allow the AppImage to run as a program, or install the DEB.

[Installation guide](https://github.com/ZLHRS/codex-anime-themes#installation)

Existing users can choose Check for updates in Studio (the update button is under Settings). The selected theme and its settings are preserved. SHA-256 checksums are provided in SHA256SUMS.txt.

A compatible desktop ChatGPT app is required separately. Real theme application has been verified on Windows; Mac and Linux builds pass automated tests, but connection to the actual ChatGPT app remains unverified.
