# ZLHRS Theme Studio 2.6.7

- Includes all 85 themes and their current artwork and gallery previews.
- Adds the recent character themes, full-screen scenes and artwork refinements.
- Corrects Crimson Stained Glass orientation and increases its contrast and saturation.
- Supports animated theme media, with playback paused when inactive.
- Keeps the existing 23 custom pets; no new pets were created.
- Verifies live English / Russian switching, persistence after reload, translated gallery text and search.
- Provides English README, gallery, setup instructions and portable start guide.

## Local packages

- Windows x64 portable ZIP: extract the entire archive and open ZLHRS Theme Studio.exe.
- Source ZIP: for development; requires Node.js and npm dependencies.
- SHA-256 checksums: SHA256SUMS-2.6.7.txt.

These packages are prepared locally and are not a published GitHub release. New macOS and Linux binaries are not included in this local build; the repository's platform build workflow remains available.

## Language

Open Settings > Interface language and choose English or Russian. The selection is saved automatically. Switching languages preserves the selected theme and artwork settings.

## Requirements

A compatible desktop ChatGPT app is required separately. Theme application is verified on Windows. Real ChatGPT connection on macOS and Linux remains unverified.
