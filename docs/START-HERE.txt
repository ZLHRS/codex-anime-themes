ZLHRS Theme Studio — 1.6.0

1. Склонируйте репозиторий или распакуйте ZIP целиком.
2. Дважды нажмите ZLHRS Theme Studio.exe. Установка и создание ярлыков выполняются автоматически.
3. Выберите тему и нажмите «Применить». Выбор сохраняется для следующих запусков.
4. В дальнейшем запускайте ChatGPT новым ярлыком на рабочем столе или в меню Пуск: последняя тема включается сама.
5. Чтобы сменить тему, откройте ярлык ZLHRS Theme Studio.

Если ChatGPT уже открыт обычным способом, полностью закройте его и запустите новым ярлыком. Выбранная тема уже сохранена.
Старый закреплённый значок на панели задач замените новым. Прямой запуск EXE или из Store обходит темы.
Для обновления выполните git pull и снова откройте ZLHRS Theme Studio.exe. Выбранная тема сохраняется.
START.cmd — дополнительный способ того же запуска.
Нужны Windows 10/11 и установленный Codex / ChatGPT (пакет OpenAI.Codex). Node.js и Codex App Manager не требуются. Codex App Manager нужно закрыть перед применением темы.
Установленная копия: %LOCALAPPDATA%\ZLHRS\ThemeStudio. После установки исходную папку можно переместить.
