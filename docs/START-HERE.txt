# ZLHRS Theme Studio — 1.3.0

1. Распакуйте комплект, откройте START.cmd.
2. В каталоге с широкими превью выберите тему кнопкой «Применить тему».
3. Нажмите «Настроить запуск». Комплект установится в локальную папку пользователя.
4. Теперь открывайте ChatGPT новым одноимённым ярлыком на рабочем столе: последняя тема включается автоматически, без окна выбора.
5. Для смены темы откройте ярлык ZLHRS Theme Studio.

Старый закреплённый значок ChatGPT может обходить запуск тем. Открепите его и закрепите новый ярлык. Открытие приложения из Microsoft Store или напрямую из EXE не перехватывается.
Первый раз полностью закройте ранее открытое обычным способом приложение. Не запускайте параллельно Codex App Manager.
Нужны Windows 10/11 и установленный Codex / ChatGPT (OpenAI.Codex). Node.js и отдельный менеджер не нужны.
Темы и программа копируются в %LOCALAPPDATA%\ZLHRS\ThemeStudio. Выбранная тема хранится там же в .selected-theme.json. Исходный скачанный архив после установки больше не нужен.
Существующий одноимённый ярлык сохраняется с расширением .before-theme-studio.bak; установки других программ не изменяются.
