Версия 1.1.0 — запуск без команд

1. Скачайте ZIP или клонируйте репозиторий. Распакуйте архив целиком.
2. Дважды нажмите START.cmd.
3. Выберите тему слева и нажмите «Применить / открыть».

Нужна Windows 10/11 и установленный настольный Codex / ChatGPT (пакет OpenAI.Codex).
Меню выбора, 16 тем, превью и механизм применения уже в комплекте.
Node.js и Codex App Manager не требуются. Само приложение ChatGPT/Codex в набор не входит.

При первом запуске полностью закройте ранее открытое приложение, затем нажмите кнопку в меню тем. Приложение откроется с поддержкой тем.
После этого темы переключаются через меню без перезапуска приложения. Окно выбора можно закрыть: тема останется.
В дальнейшем открывайте приложение через START.cmd и кнопку «Применить / открыть».

Если работает Codex App Manager, сначала закройте его: он может возвращать другую тему.
Если запуск не удался, окно покажет причину. Дополнительные сведения могут появиться в .theme-error.log рядом с START.cmd.
Папку комплекта не удаляйте и не перемещайте, пока приложение работает.

Чтобы вернуть обычный вид, полностью закройте приложение и откройте обычным ярлыком.
