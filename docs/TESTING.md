# Проверка Theme Studio

## Фоновая память и переходы, 8 ноября 2026

Закрытие галереи уничтожает её окно; smoke-проверка подтверждает повторное открытие с сохранением темы и настроек и работу ThemeSession без окна. Старый PowerShell используется только для остановки прежнего движка, затем блокировку держит небольшой .NET-помощник (при отсутствии компилятора сохранён прежний вариант).

Пройдены 7 проверок настроек/сессии, проверка блокировки старого движка, Chromium lifecycle и smoke галереи. При замене страницы Chromium проверяет наличие оформления и фона уже в первом кадре. В установленной portable-версии подтверждён runtime без задержки. Сумма рабочих наборов Studio с помощником: около 290–293 МБ против прежних 365 МБ; помощник 14 МБ вместо 90 МБ. Фоновый замер CPU за 15 секунд: 0,017% общей мощности. Это моментальные замеры, сумма рабочих наборов включает общие страницы памяти и не учитывает отрисовку темы внутри ChatGPT.

## Автоматические сценарии

`npm test`:
- доступность IPv4/IPv6 и отказ внешним адресам;
- 16 корректных payload;
- выбор темы, повторное применение и смена темы;
- отсутствие окна и загрузка оболочки: отсутствие ложного сообщения об успехе;
- восстановление CSS после удаления;
- сериализация переключения и фоновой проверки;
- сохранение настроек;
- отсутствие обновления для одинаковой/старой версии;
- выбор архива своей платформы, проверка SHA-256, повреждение файла и ошибка сети.

`npm run test:integration` запускает отдельное тестовое Electron-приложение с настоящим Chromium. Проверяет все 16 тем в основном и отдельном окне, reload, завершение и повторный запуск. Проверка специального признака тестового окна предотвращает изменение пользовательских чатов. В Linux без дисплея запускается через `xvfb-run -a`.

`electron . --smoke-test` проверяет интерфейс, поиск, превью, инструкцию, запись настоящего ярлыка во временную папку и маршрутизацию запуска. Это дополняет интеграционный тест, но не заменяет его.

## Проверка на компьютере пользователя

8 ноября 2026: в открытом ChatGPT Windows обнаружен IPv6 endpoint ::1:9345. Все 16 тем применены и проверены чтением состояния runtime и CSS без чтения переписки; затем восстановлена выбранная furina-moonlit-repose. Перезапуск пользовательского ChatGPT и macOS вручную не выполнялись: lifecycle проверен на изолированном Electron-приложении.

Готовые программы и архивы хранятся в GitHub Releases. В Git находятся только исходники, ресурсы и тесты.

## Исправление запуска 2.3.1

8 ноября 2026: воспроизведён отказ после повторного запуска: порт 9345 занят, но HTTP endpoint недоступен. После полного выхода через «Файл → Выйти из ChatGPT» настоящий ярлык запустил приложение на свободном порте 9346. Выбранная fubuki-velvet подтверждена и визуально, и по runtime/CSS. Обычное закрытие окна оставляет процесс в фоне; если штатное закрытие не завершает процесс, Studio возвращает окно и сообщает точный пункт полного выхода, без принудительного завершения.

Добавлены проверки занятого порта, сохранённого порта и выполнения помощника под Windows PowerShell. Интеграционный тест выбирает свободный порт и проверяет 16 тем и повторный запуск в изолированном Chromium.

## Автоматический перезапуск 2.3.2

8 ноября 2026: с разрешения владельца проверен настоящий ChatGPT. Экземпляр без параметров подключения был запущен обычным способом; ярлык Studio автоматически завершил его и открыл новый с параметрами подключения. Тема fubuki-velvet подтверждена по runtime и CSS. Ручной выход через меню не понадобился. Принудительное завершение ограничено выбранным EXE, основным процессом и повторной проверкой времени его создания.

19 проверок прошли, включая отдельный сценарий перезапуска приложения, которое отменяет обычное закрытие. При исправном подключении повторный запуск ярлыка сохраняет текущий процесс ChatGPT.

## Поле ввода 2.3.3

Все 16 тем проверены в настоящем ChatGPT: значок ::after скрыт, боковые детали скрыты в 14 темах, редактор остаётся доступен, его прокрутка не меняется. В Bunny Refrain сохранены ушки, в Zero Two — рожки. После проверки восстановлена blue-cat-nocturne. По снимкам обрезанный значок и лишние уголки устранены; тёмная полоса над нижним баром ещё видна, несмотря на отключение отдельной фоновой подложки.

## Настройки и эффекты 2.4.0

Добавлены проверки ограничений значений, 16 наборов эффектов, отключения движения и изменения подписи payload при изменении настроек. В настоящем Chromium проверены яркость, размер, сохранение исходного поворота картинки, отключение анимаций и удаление слоя при выключении эффектов. UI smoke-тест меняет ползунок и переключатель через обработчики интерфейса, сохраняет настройки на диск, переключает тему и проверяет независимость значений. Собранная Windows-версия прошла этот же тест. В реальном ChatGPT подтверждены слой эффекта, отсутствие перехвата нажатий, исходная яркость и масштаб активной blue-cat-nocturne.

## Полоса над полем ввода 2.4.1

В настоящем ChatGPT найден отдельный градиент высотой 32 пикселя внутри закреплённого отступа, вне нижнего бара. После установки собранной версии и удаления временного проверочного стиля снимок подтвердил отсутствие полосы. Скрывается только декоративный слой; отступ и прокрутка сохранены. Все 22 проверки прошли: для каждой из 16 тем в двух окнах Chromium проверены скрытие градиента, сохранение высоты отступа и видимости постороннего слоя. Подпись применяемого оформления теперь учитывает изменения общего runtime, чтобы обновление не пропускалось при неизменном CSS темы.

## Темы Каны 2.5.0

Проверены 17 тем в двух тестовых окнах Chromium: 22 проверки прошли. Собранное приложение прошло UI smoke-тест. Обе новые темы применены в настоящем ChatGPT: фон покрывает область 2036 × 1344, у рубиновой темы размеры слоя обменены и подтверждён поворот −90°. Исходные PNG сохранены без изменений. Превью просмотрены; включена kana-ruby-spotlight.

## Реальная кнопка обновления Windows (2.5.4)

8 ноября: официальный portable 2.5.2 через прежний ярлык не смог обновиться до 2.5.3: дочерний PowerShell завершался вместе со Studio. В исправленной тестовой сборке с номером 2.5.2 кнопка скачала официальный ZIP 2.5.3, проверила его, самостоятельно заменила файлы и открыла видимое окно с сообщением об успехе. Номер тестовой сборки был снижен только для проверки наличия обновления; исправление включено в 2.5.4.

После полного выхода из Studio запущен прежний «ChatGPT с темой»: runtime подтвердил kana-ruby-spotlight, ready=true, styled=true. Затем прежний «ZLHRS Theme Studio» открыл окно. У обоих ярлыков сохранились пути, аргументы и время создания. Выбранная непосредственно перед обновлением тема и вся карта appearance совпали после обновления. Добавлен автоматический тест независимого запуска помощника с кавычками, пробелами и кириллицей.

## Сравнение запуска, 8 ноября 2026

Независимый помощник полностью закрывал оба приложения, затем измерял появление главного окна Windows одинаковым опросом каждые 100 мс. До изменения: обычный запуск 8,332 с, запуск с подключением без темы 8,007 с, Studio 10,004 с. После параллельной подготовки: обычный 8,350 с, Studio 9,189 с. Готовность оболочки и выбранной темы после запуска Studio подтверждена на 20,928 с; появление окна не приравнивается к готовности чата. Это единичные последовательные замеры, а не статистическая гарантия.

ChatGPT запускается параллельно с подготовкой блокировки старого движка и чтением каталога. Уже запущенный при подготовке процесс не запускается и не завершается повторно. Ошибка показа окна не отменяет применение темы; фоновое восстановление остаётся включённым. Windows восстанавливает окно напрямую, без ожидания неподдерживаемых команд браузерного окна. Проверены запуск с первого раза и восстановление свёрнутого окна.

## Перекрытие левой части рабочего стола, 11 ноября 2026

Во время жалобы обнаружено видимое служебное окно ChatGPT 1122×1440 в позиции 0,0 с WS_EX_TOOLWINDOW и WS_EX_TOPMOST. Основное окно ChatGPT имело такое же название. Прежний focus-app.ps1 выбирал первое совпадение заголовка и мог показывать скрытое служебное окно. Добавлен пропуск WS_EX_TOOLWINDOW и WS_EX_NOACTIVATE. Подтверждённое перекрывающее окно скрыто после проверки пути владельца и флагов; основной чат не закрывался. После установки и повторного запуска через --launch служебное окно осталось скрытым, основное — видимым.
