# Проверка Theme Studio

## Автоматические сценарии

`npm test`:
- доступность IPv4/IPv6 и отказ внешним адресам;
- 16 корректных payload;
- выбор темы, повторное применение и смена темы;
- отсутствие окна и загрузка оболочки: отсутствие ложного сообщения об успехе;
- восстановление CSS после удаления;
- сериализация переключения и фоновой проверки;
- сохранение настроек;
- отсутствие обновления для одинаковой/старой версии;
- выбор архива своей платформы, проверка SHA-256, повреждение файла и ошибка сети.

`npm run test:integration` запускает отдельное тестовое Electron-приложение с настоящим Chromium. Проверяет все 16 тем в основном и отдельном окне, reload, завершение и повторный запуск. Проверка специального признака тестового окна предотвращает изменение пользовательских чатов. В Linux без дисплея запускается через `xvfb-run -a`.

`electron . --smoke-test` проверяет интерфейс, поиск, превью, инструкцию, запись настоящего ярлыка во временную папку и маршрутизацию запуска. Это дополняет интеграционный тест, но не заменяет его.

## Проверка на компьютере пользователя

8 ноября 2026: в открытом ChatGPT Windows обнаружен IPv6 endpoint ::1:9345. Все 16 тем применены и проверены чтением состояния runtime и CSS без чтения переписки; затем восстановлена выбранная furina-moonlit-repose. Перезапуск пользовательского ChatGPT и macOS вручную не выполнялись: lifecycle проверен на изолированном Electron-приложении.

Готовые программы и архивы хранятся в GitHub Releases. В Git находятся только исходники, ресурсы и тесты.

## Исправление запуска 2.3.1

8 ноября 2026: воспроизведён отказ после повторного запуска: порт 9345 занят, но HTTP endpoint недоступен. После полного выхода через «Файл → Выйти из ChatGPT» настоящий ярлык запустил приложение на свободном порте 9346. Выбранная fubuki-velvet подтверждена и визуально, и по runtime/CSS. Обычное закрытие окна оставляет процесс в фоне; если штатное закрытие не завершает процесс, Studio возвращает окно и сообщает точный пункт полного выхода, без принудительного завершения.

Добавлены проверки занятого порта, сохранённого порта и выполнения помощника под Windows PowerShell. Интеграционный тест выбирает свободный порт и проверяет 16 тем и повторный запуск в изолированном Chromium.
