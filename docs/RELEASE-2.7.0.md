# ZLHRS Theme Studio 2.7.0 — GPT + Claude

One Studio for ChatGPT and Claude Desktop, with 99 themes.

## Downloads

- **Windows portable ZIP:** extract the entire folder and open ZLHRS Theme Studio.exe.
- **Windows installer:** normal desktop installation.
- **Claude Themes ZIP:** optional standalone data-only pack for the community mod. Compressed artwork and static video posters; use Studio for the full original-quality compositions.
- **Source ZIP:** project source for development.

## Changes

- Separate ChatGPT and Claude buttons, selections and image settings.
- Original Claude compositions: full backgrounds, rotations, mirrored artwork, paired characters and original image quality.
- The left Claude navigation follows the palette; opening the right panel keeps artwork fixed.
- Three independent shortcut buttons: ZLHRS Theme Studio, Claude Theme and ChatGPT Theme.
- New ribbon-Z Studio logo and warm-star Claude logo; the existing ChatGPT icon is retained.
- 12 Live ASCII scenes, supported animated artwork and a personal theme library preserved through updates.
- Cleaned the signature from Quiet Gesture / Sapphire and refreshed its preview.
- Updated English/Russian interface and Claude setup documentation. ChatGPT Pets remain separate from Claude.

## Claude setup

Install the community Claude Desktop Themes mod and extension once via /themes, then fully restart Claude. Choose themes directly with the Claude button in Studio. See [the setup guide](https://github.com/ZLHRS/codex-anime-themes/blob/v2.7.0/docs/CLAUDE-CODE.md).

## Validation and scope

Windows release. 47 automated unit tests; all 99 exports validated and rendered; 261 composition comparisons across three sizes for 87 non-ASCII themes. Listed complex compositions and all three shortcut buttons were also checked in the installed apps. macOS/Linux source support is retained, but this release does not claim live Claude verification on those systems. Community integration; app updates can affect compatibility.
