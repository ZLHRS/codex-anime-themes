# ZLHRS Theme Studio 2.6.0

- A public collection of 16 unique characters for built-in ChatGPT Pets. Each character’s pet is shared across its themes; selection remains manual.
- Add pets through ChatGPT copies a shared prompt with collection links and opens ChatGPT. Paste and send it in a chat with Pets available. Existing pets are skipped, and the active pet is not switched.
- New pets have transparent backgrounds, nine animations, and 16 look directions. Large source files are not included in the Studio installation.
- The shortcut button updates Studio and themed ChatGPT links on the desktop and in Start. Normal startup does not restore deleted shortcuts.
- ChatGPT settings use the selected theme’s colors instead of a black background.

Studio does not import pets directly into your account. To add them, send the copied prompt in ChatGPT with Pets available.
