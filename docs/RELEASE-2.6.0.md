# ZLHRS Theme Studio 2.6.0

- Публичный набор из 16 уникальных персонажей для встроенных ChatGPT Pets. Один питомец используется для всех тем с тем же персонажем; выбор остаётся ручным.
- Кнопка «Добавить питомцев через ChatGPT» копирует общий запрос со ссылками на набор и открывает ChatGPT. Вставьте и отправьте его в чате с доступным Pets. Уже добавленные питомцы пропускаются, активный питомец не переключается.
- Новые питомцы имеют прозрачный фон, девять анимаций и 16 направлений взгляда. Большие исходники не входят в установку Studio.
- Кнопка создания ярлыков обновляет ссылки Studio и ChatGPT с темой на рабочем столе и в меню «Пуск». Удалённые ярлыки не восстанавливаются при обычном запуске.
- Настройки ChatGPT используют цвета выбранной темы вместо чёрного фона.

Studio не импортирует питомцев напрямую в аккаунт: для добавления требуется отправить скопированный запрос в ChatGPT с доступной функцией Pets.
