# 1.3.0

- Переработана вкладка скинов по визуальному образцу Codex App Manager: боковая панель, две колонки, тёмные карточки и сиреневые кнопки.
- Описания, версии, авторы и палитры на карточках; подробности отдельной кнопкой.
- Поиск по имени, описанию и автору, фильтр выбранной темы, компактный вид списка.
- Интерфейс реализован на встроенном Windows WPF, без новых зависимостей.

# 1.2.0

- Новый интерфейс: сетка карточек, широкие превью, поиск и отметка выбранной темы.
- Установка в локальную папку пользователя и два ярлыка: ChatGPT / Theme Studio.
- Ярлык ChatGPT автоматически включает последнюю тему без открытия каталога.
- При замене существующих ярлыков создаются резервные копии.

# 1.1.0

- Добавлено встроенное окно выбора всех 16 тем с превью.
- START.cmd открывает меню двойным щелчком.
- Автономный механизм применения на Windows PowerShell: больше не нужен Node.js или установленный Codex App Manager.
- Переключение темы в открытом приложении, если оно запущено через меню.
- Отдельный локальный файл выбора, без изменения настроек стороннего менеджера.
- Сообщения о конфликтующем менеджере и неподдерживаемом запуске вместо принудительного завершения процессов.
- Обновлены ZIP и инструкция.
