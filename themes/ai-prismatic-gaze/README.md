# Ай Хосино · Prismatic Gaze

![Превью](../../previews/ai-prismatic-gaze-chat.jpg)

Звёздный взгляд, индиго и неоновые блики.

Горизонтальная иллюстрация, тёмная панель, контрастные ответы, оформление поля ввода и декоративные эффекты. Поддерживаются настройки яркости, масштаба, положения и отключение анимации.

Изображение предоставлено пользователем и улучшено встроенным редактором изображений; авторство исходной иллюстрации не заявляется. Для личного использования.
