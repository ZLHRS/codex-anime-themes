# Crimson · Heart Duo

![Превью](../../previews/crimson-heart-duo-chat.jpg)

Первое изображение пользователя — справа, второе — слева. Версия 1.1.0: портреты улучшены генеративной перерисовкой, фон удалён с сохранением прозрачности. Лица, позы и одежда использованы как ориентир исходников. Исходники сохранены.

Настройки яркости, масштаба и положения применяются к обоим портретам. Рубиново-розовая палитра, сердца и оформление поля ввода, включая пустой чат.

Изображения предоставлены пользователем; авторство исходных иллюстраций не заявляется. Для личного использования.

Версия 1.2.0: дорисованы боковые контуры волос и силуэтов, добавлен прозрачный запас. Изображения вписываются целиком по ширине, без вертикального среза со стороны чата.
