# Silver · Azure Bloom

![Превью](../../previews/silver-azure-bloom-chat.jpg)

Серебряные волосы, белые цветы и сияние сапфирового глаза.

Горизонтальная иллюстрация, согласованные цвета панели и поля ввода, контрастная подложка ответа, декоративные эффекты. Поддерживает яркость, масштаб, положение и отключение анимации.

Исходное изображение предоставлено пользователем. Исходник повёрнут на 90° против часовой стрелки; слегка повышена резкость обычным фильтром без генеративной перерисовки. Цвета, геометрия и детали рисунка сохранены. Авторство исходной иллюстрации не заявляется. Для личного использования.
