# Ivory · Midnight Frame

![Превью](../../previews/ivory-midnight-frame-chat.jpg)

Тема на основе изображения пользователя, без перерисовки. Бежево-графитовая палитра, лавандовые акценты, тёмная подложка ответов и оформление поля ввода, включая пустой чат. Поддерживаются настройки яркости, масштаба, положения и эффектов.

Авторство исходного изображения не заявляется. Для личного использования.
