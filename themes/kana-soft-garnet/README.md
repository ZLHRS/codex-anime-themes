# Кана · Тёплый гранат

![Превью темы в чате](../../previews/kana-soft-garnet-chat.jpg)

Мягкий бордовый фон, тёплый свет и спокойный портрет Каны по центру.

Выберите тему в ZLHRS Theme Studio. Яркость, размер, положение, эффекты и анимации настраиваются отдельно. Используется версия с восстановленной нейросетью чёткостью; мелкие детали могут отличаться от исходника.
