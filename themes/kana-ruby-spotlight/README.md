# Кана · Рубиновый свет

![Превью темы в чате](../../previews/kana-ruby-spotlight-chat.jpg)

Горизонтальный крупный план Каны, рубиновые акценты и звёздные блики.

Выберите тему в ZLHRS Theme Studio. Яркость, размер, положение, эффекты и анимации настраиваются отдельно. Используется версия с восстановленной нейросетью чёткостью; мелкие детали могут отличаться от исходника. Поворот на 90° выполняется стилями темы.
