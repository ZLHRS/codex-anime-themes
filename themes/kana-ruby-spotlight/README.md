# Кана · Рубиновый свет

![Превью темы в чате](../../previews/kana-ruby-spotlight-chat.jpg)

Горизонтальный крупный план Каны, рубиновые акценты и звёздные блики.

Выберите тему в ZLHRS Theme Studio. Яркость, размер, положение, эффекты и анимации настраиваются отдельно. Исходная картинка сохранена без перерисовки. Поворот на 90° выполняется стилями темы.
