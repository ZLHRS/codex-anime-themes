# Фурина · Silver Slumber

![Превью](../../previews/furina-silver-slumber-chat.jpg)

Спокойный сон, серебристые пряди и мягкие бирюзовые блики.

Горизонтальная иллюстрация, согласованные цвета панели и поля ввода, контрастная подложка ответа, декоративные эффекты. Поддерживает яркость, масштаб, положение и отключение анимации.

Исходное изображение предоставлено пользователем. Обработано встроенным редактором: горизонтальная ориентация, очистка артефактов и уточнение деталей с сохранением палитры и персонажа. Авторство исходной иллюстрации не заявляется. Для личного использования.
