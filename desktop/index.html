БЫСТРЫЙ СТАРТ

Три шага к своему пространству

  1. Выбери тему. Открой «Темы» и нажми «Применить» на понравившейся карточке. В Windows Studio перезапустит ChatGPT, если нужно — сначала сохрани неотправленный текст. На Mac и Linux перед первым применением закрой ChatGPT.
  2. Настрой под себя. В «Настройках» можно поменять яркость, размер и положение картинки.
  3. Сделай ярлык. В «Настройках» нажми «Создать / обновить ярлыки». В следующий раз открывай «ChatGPT с темой» — последняя тема включится сама.

Как обновиться

Открой «Настройки» → «Подтянуть изменения». Studio скачает и проверит готовый выпуск, обновится и перезапустится.

Если версия уже свежая, приложение сообщит об этом. В Linux при установке DEB система может попросить пароль. На Mac для папки без доступа на запись потребуется ручная установка.

Если не запускается

В «Настройках» нажми «Выбрать приложение» и укажи установленный ChatGPT. Полностью закрой обычный ChatGPT и повтори запуск через Studio.

Закрой старый Theme Studio и другие менеджеры тем, чтобы они не меняли оформление одновременно.

Крестик закрывает галерею, но тема продолжает работать. Чтобы завершить работу полностью, нажми «Выйти из Studio». Готовый ZIP распаковывай целиком: файлы приложения должны оставаться рядом.
