Настроить выбранную тему

Изменения сохраняются отдельно для каждой темы. После настройки нажмите «Применить настройки». В теме с двумя персонажами картинка перемещается целиком.

При отключении анимаций украшения остаются неподвижными. Системная настройка уменьшения движения тоже учитывается.

Как поставить тему

Распакуйте готовый ZIP целиком и откройте ZLHRS Theme Studio.exe. Установка не нужна. Все файлы папки должны оставаться рядом.

  1. В Windows Studio сама перезапустит ChatGPT, если это необходимо. Сохраните неотправленный текст. На Mac и Linux перед первым применением закройте ChatGPT.
  2. Откройте вкладку «Скины» и нажмите «Применить» на понравившейся теме.
  3. Нажмите «Создать ярлык «ChatGPT с темой»». Кнопка «Показать ярлык» поможет найти его.
  4. В дальнейшем открывайте «ChatGPT с темой» с рабочего стола — последняя тема включится сама, без открытия галереи Studio. Этот отдельный ярлык со значком Studio не заменяет обычный ChatGPT.

Как обновиться

Нажмите «Подтянуть изменения». Если есть новый выпуск, Studio скачает его, проверит файл, установит и перезапустится. Выбранная тема сохранится.

Если установлена последняя версия, приложение сообщит об этом и останется открытым. Обновления — готовые выпуски с GitHub, а не незавершённые изменения исходников.

В Linux при установке DEB система может попросить пароль. Если папка приложения на Mac недоступна для записи, потребуется установить обновление вручную.

Если не запускается

Нажмите «Выбрать приложение» и укажите установленный ChatGPT. Не выбирайте Codex CLI. Если ChatGPT уже открыт обычным способом, полностью закройте его и повторите запуск здесь.

Старый значок ChatGPT на панели задач замените новым. Codex App Manager и прежнюю версию Theme Studio закройте, чтобы они не меняли тему одновременно.

Крестик закрывает галерею и освобождает её память; тема продолжает работать в фоне без значка в трее. Чтобы снова открыть галерею, запустите Studio через Пуск. Чтобы полностью завершить работу, нажмите «Выйти из Studio».
