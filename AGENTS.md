# Character pets

Current user override: do not create pets until the user explicitly requests them again.

When preparing character artwork, preserve the original pose, clothing and facial
expression. Only improve quality, remove the background, and complete clipped
edges as needed. Do not substitute redesigned clothing or a different pose when
generation fails; retain the original and report the unfinished processing.

When adding a character theme, also prepare a matching chibi companion for the
built-in ChatGPT Pets feature. Reuse an existing validated pet for the same
character across themes; do not create duplicates for palette variants.

The user chose manual pet selection. Do not add experimental automatic switching,
private ChatGPT settings API calls, or a replacement Theme Studio pet overlay.

Use the installed work-pets creation workflow for artwork, animation validation,
previews, upload and verification. Keep source artifacts in `pets/runs/<character>`
and Library. Record stable pet IDs only after successful creation. A draft image
or unvalidated sprite sheet is not a completed pet; report unfinished work plainly.

User-confirmed identities: Azure Morpho = Roxy, Ivory Midnight Frame = Kurumi,
Silver Edge = Sora, Tidal Halo and Twin Current = Noelle. Do not create pets for
Silver Azure Bloom or Crimson Heart Duo. New pets should use detailed chibi art
on native transparent backgrounds, preserving costume and facial detail at pet size.
Public sharing of this character set for all Theme Studio users was authorized.

Do not publish pet share links without the user's audience confirmation. A pet ID
belongs to its user's library; it is not a globally installable theme asset.
